## 1. 产品概述

### 1.1 产品定位

xinsight 是一款**多 Agent AI 数据洞察助手**，帮助用户通过自然语言对话，从多种异构数据源（REST API、GraphQL、gRPC、MQTT、OPC UA）中智能查询、分析和可视化数据。

### 1.2 目标用户

| 角色            | 需求                                                      |
| --------------- | --------------------------------------------------------- |
| 数据分析师      | 无需编写代码即可查询和交叉分析多系统数据                  |
| 运维/IoT 工程师 | 实时监控工业设备（OPC UA/MQTT），通过自然语言获取设备状态 |
| 产品经理        | 快速从业务 API 提取关键指标，生成图表报告                 |
| 开发者          | 调试 API、探索数据结构、验证接口返回                      |

### 1.3 核心价值主张

- **零代码数据访问**：自然语言 → AI 理解意图 → 自动调用正确 API → 结构化展示
- **多源聚合**：单次对话同时查询多个数据源，跨源关联分析
- **智能 Schema 感知**：Agent 自动了解数据结构，生成精准查询
- **可扩展架构**：插件式适配器设计，新协议即插即用

## 3. 非功能需求

### 3.1 性能

| 指标         | 要求                                 |
| ------------ | ------------------------------------ |
| 首屏加载     | < 2s（Turbopack + Next.js 16 优化）  |
| 流式响应延迟 | 首 token < 1s（取决于 LLM provider） |
| API 响应时间 | 数据源 CRUD < 200ms                  |
| 数据库查询   | 单次查询 < 50ms（SQLite 本地）       |

### 3.2 可靠性

| 指标       | 要求                                  |
| ---------- | ------------------------------------- |
| 数据源重试 | 失败自动重试（指数退避），最多 3 次   |
| 错误处理   | 所有 API 返回结构化错误，前端友好展示 |
| 数据持久化 | SQLite 本地存储，支持备份恢复         |

### 3.3 安全性

| 指标       | 要求                              |
| ---------- | --------------------------------- |
| 认证       | Session-based，httpOnly cookie    |
| 密码存储   | bcrypt 哈希                       |
| API 密钥   | 仅存于 .env.local，不提交版本控制 |
| 数据源凭证 | 加密存储在 DB 的 auth 字段中      |
| 路由保护   | middleware 统一拦截未认证请求     |

### 3.4 可扩展性

| 方面            | 设计                                                  |
| --------------- | ----------------------------------------------------- |
| 新协议适配器    | 实现 Adapter 接口即可接入                             |
| 新 Agent        | Mastra agent 配置 + 工具绑定                          |
| 新 LLM Provider | 在 models.ts 注册即可                                 |
| 跨平台          | Next.js static export → Tauri(桌面) / Capacitor(移动) |

### 4.2 数据模型

| 表名                | 用途                                                      |
| ------------------- | --------------------------------------------------------- |
| `users`             | 用户账号（id, username, displayName, passwordHash, role） |
| `sessions`          | 登录会话（id, userId, expiresAt）                         |
| `datasources`       | 数据源配置（含 endpoints JSON、auth JSON、config JSON）   |
| `agent_datasources` | Agent ↔ 数据源多对多关联                                  |
| `chats`             | 聊天会话（含 agentId, modelId）                           |
| `messages`          | 聊天消息（parts JSON 存储多部分内容）                     |

### 4.3 关键技术选型

| 组件        | 选型                    | 理由                                |
| ----------- | ----------------------- | ----------------------------------- |
| 运行时      | Bun                     | 极速启动、内置 SQLite、兼容 Node.js |
| 框架        | Next.js 16              | App Router + Turbopack + React 19   |
| AI 框架     | Mastra (library)        | Agent/Tool/Workflow 统一抽象        |
| AI SDK      | Vercel AI SDK v6        | 流式 UI、多 provider 统一接口       |
| ORM         | Drizzle                 | 类型安全、轻量、支持 bun:sqlite     |
| Schema 校验 | Zod v4                  | 运行时类型校验 + TypeScript 推导    |
| UI 组件     | AI Elements + shadcn/ui | 专为 AI 聊天场景设计                |

## 5. 用户故事

### 5.1 核心用户旅程

**场景 1：首次使用**

1. 用户注册账号
2. 管理员配置数据源（如公司内部 REST API）
3. 将数据源绑定到 Agent
4. 用户开始对话："帮我查一下今天的订单数量"
5. Agent 自动调用正确的 API 端点，返回结果 + 图表

**场景 2：跨源分析**

1. 用户问："对比 A 系统的销量和 B 系统的库存"
2. Agent 识别需要查询两个数据源
3. 并行调用两个 API，聚合结果
4. 生成对比图表 + 文字洞察

**场景 3：知识增强**

1. 管理员上传产品文档 PDF
2. 系统自动提取文本、分块索引
3. 用户问："产品 X 的技术参数是什么？"
4. Agent 结合知识库 + 数据源给出完整答案

## 7. 约束与限制

| 约束         | 说明                                              |
| ------------ | ------------------------------------------------- |
| 本地部署优先 | SQLite 不适合高并发写入，适合单机/小团队          |
| LLM 依赖     | 核心功能依赖外部 LLM API，需联网                  |
| 协议限制     | gRPC/MQTT/OPC UA 适配器需要目标服务支持           |
| 浏览器兼容   | 现代浏览器（Chrome/Firefox/Safari/Edge 最新两版） |

## 8. 术语表

| 术语                | 定义                                           |
| ------------------- | ---------------------------------------------- |
| Agent               | AI 智能体，具备特定能力和工具的对话实体        |
| 数据源 (Datasource) | 外部数据服务的连接配置，包含认证信息和端点列表 |
| 端点 (Endpoint)     | 数据源内的具体 API 接口/主题/节点              |
| 适配器 (Adapter)    | 将统一查询接口翻译为特定协议调用的组件         |
| Schema              | 数据源返回数据的字段结构描述                   |
| Tool                | Mastra 框架中 Agent 可调用的功能单元           |
| Wiki                | 知识库，存储非结构化文档供 Agent 检索          |
